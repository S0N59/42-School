# 42 School Projects Portfolio

This repository contains 5 core projects completed during my studies at [42 School](https://42yerevan.am/en). Each project is written in C and demonstrates foundational programming concepts including memory management, file I/O, custom libraries, and basic graphics handling.

## 📌 Projects Included

### 1. 🧱 Libft
Custom implementation of common C standard library functions.
- Manual memory management
- String manipulation
- Linked lists

### 2. 📄 Get Next Line
Reads a line from a file descriptor, one line at a time.
- Dynamic buffer management
- File reading logic

### 3. 🖨️ ft_printf
A reimplementation of the `printf` function in C.
- Variadic functions
- Format parsing
- Custom output formatting

### 4. 🔗 Pipex
Handles Unix pipe and process execution (like `< infile cmd1 | cmd2 > outfile`).
- Process forking
- Piping and redirection
- `execve` system call

### 5. 🎮 So_long
A simple 2D game using the MiniLibX graphical library.
- Map parsing
- Event handling
- Sprite-based movement

## 🛠️ Technologies
- C Language
- GNU Make
- MiniLibX (for So_long)
- Linux environment

## 📚 What I Learned
- Deep understanding of how memory and file systems work in C
- How to write modular and reusable code
- Basic graphics programming and game logic
- Real-world usage of pipes, forks, and system calls
